# Security policy

## Supported versions

Only the latest state of the `main` branch receives fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Send a report by email to **codieplusplus@apax.net** with:

- a description of the problem and its impact,
- steps or code to reproduce it,
- the OCaml version, compiler and platform you used.

You will receive an acknowledgement, and the fix will be coordinated with you
before any public disclosure.
